# GF Memory Website ❤️

## Run
1. Open `index.html` in Chrome, or use VS Code Live Server.
2. Put your real photos in `assets/photos/`.
3. Name them `photo1.jpg` through `photo10.jpg`.
4. Put your music file at `assets/music/our-song.mp3`.

## Customize
- Edit text in `index.html`.
- Change colors and layout in `style.css`.
- Add interactions in `script.js`.

This is a static website, so no database is required for the first version.
